Freischaltung ausstehend

Warum wird diese Seite angezeigt?

Sie wurden erfolgreich angemeldet, Ihr Konto wurde jedoch noch nicht durch einen Systemadministrator freigeschaltet. Deshalb ist aktuell noch kein Zugriff auf NODE möglich.

Was bedeutet das für Ihr Konto?

Bis zur Freischaltung können Sie in NODE momentan keine weiteren Aktionen ausführen. Ihr Konto bleibt so lange in der Freigabewarteschlange, bis eine Berechtigung erteilt wurde.

@if (displayName && username) { Aktueller Nutzer: {{ displayName }} ({{ username }})
} @else { Aktueller Nutzer: Nicht verfügbar
} Status: Nicht freigeschaltet

Was können Sie jetzt tun?

Falls Ihre Freischaltung inzwischen erfolgt ist, können Sie Ihre aktuellen Nutzerdaten erneut laden. Sobald Ihr Konto freigeschaltet ist, werden Sie automatisch zum Dashboard weitergeleitet.
